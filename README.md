## Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. Light and dark themes follow the visitor's system setting and can be switched from the nav.

| File | Purpose |
| --- | --- |
| `index.html` | Page content |
| `style.css` | Styling and light/dark themes |
| `script.js` | Theme toggle and active nav highlighting |
| `resume.pdf` | Resume linked from the Download resume button |
| `profile.jpeg`, `*.png` | Profile photo and project images |

To preview locally, open `index.html` in a browser, or run `python -m http.server` in this folder and visit `http://localhost:8000`.
